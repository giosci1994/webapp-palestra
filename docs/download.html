Get the GymMaster app

On your phone or computer, opened like any other app. Pick your device.

GymMaster for Android

The app opens full screen and updates itself together with the site.

Download the APK
  1. Open the downloaded file (from the notification or the Downloads folder).
  2. If Android asks, allow installing apps from this source, then go back and tap Install.
  3. Open GymMaster from your home screen.

Or install the web app: open gymmaster.casadm.uk in Chrome, then the menu ⋮ and Add to Home screen.

GymMaster on iPhone and iPad

Nothing to download: add the app to your Home Screen from Safari.

  1. Open gymmaster.casadm.uk in Safari.
  2. Tap Share at the bottom of the screen (at the top on iPad).
  3. Choose Add to Home Screen, then Add.

From the Home Screen app you can also turn on notifications (iOS 16.4 or later).

GymMaster for Windows

A light window for Windows 10 and 11 that tells you when a new version is out.

Download for Windows
  1. Open the downloaded installer.
  2. If Windows shows Windows protected your PC, choose More info and then Run anyway: the installer is not signed with a paid certificate.
  3. Open GymMaster from the Start menu.

Or install the web app: open gymmaster.casadm.uk in Edge or Chrome, then the install icon in the address bar.

GymMaster in your browser

On Mac, Linux and other systems install the web app from your browser.

Open the web app
  1. In Chrome or Edge: the install icon in the address bar, or the menu and then Install GymMaster.
  2. In Safari on Mac: File and then Add to Dock.

The downloads are the latest version published on GitHub.
