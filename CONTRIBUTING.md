# Contributing to Web-App Palestra

*Read this in other languages: [Italiano](#italiano)*

Thank you for your interest in contributing! This project is currently **Proprietary** and closed-source in terms of licensing. However, the code is public for educational and portfolio purposes. 
If you find a bug or have a suggestion, feel free to open an Issue. Pull Requests might be reviewed but please note the proprietary nature of the codebase.

## Reporting Bugs
- Check existing issues before opening a new one.
- Use the Bug Report template to provide as much detail as possible.

# Contribuire a Web-App Palestra

Grazie per l'interesse! Questo progetto è attualmente **Proprietario** (tutti i diritti riservati). Il codice è reso pubblico a scopo di portfolio e studio.
Se trovi un bug o hai un suggerimento, sentiti libero di aprire una Issue. Le Pull Request potrebbero essere esaminate, ma tieni presente la natura proprietaria del codice.

## Segnalare Bug
- Controlla le issue esistenti prima di aprirne una nuova.
- Usa il template "Bug Report" per fornire più dettagli possibili.
